安卓：设置 → 安全 → 加密与凭据 → 信任的凭据 → 查看，可对照指纹。
iOS：安装后到「证书信任设置」页，底部可查看证书详情。

安卓（Chrome / Edge）

  1. 先点上面的按钮下载证书。
  2. 打开「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」。
  3. 提示风险时选「仍然安装」，选中刚下载的 jingyang-ca.crt。
  4. 回浏览器刷新页面，地址栏不再报证书错误即可。

iPhone / iPad（Safari）

  1. 点上面的按钮，选「允许」下载描述文件。
  2. 「设置 → 已下载描述文件 → 安装」。
  3. 再到「设置 → 通用 → 关于本机 → 证书信任设置」，把 Jingyang Local Root CA 的开关打开。

装完后还进不去？

  1. 确认地址是 https:// 开头。业务只走 443 和 8443。
  2. 18099 只是这个证书下载页，打不开业务功能，别在那里登录。
  3. 确认手输的是 42.193.104.148，不要带 www。

这套方案的可信边界

只有「手动安装了本页根证书」的设备，才会把我们的 HTTPS 入口视为可信。 没装证书的手机仍然会报「证书不受信任」——这不是故障，是设计如此： 我们用的是自建私有 CA，不是公网受认可的 CA。

这张证书只对京阳自己的服务器起作用，别拿它去装别的用途；浏览器仍会对其它网站正常校验证书。
