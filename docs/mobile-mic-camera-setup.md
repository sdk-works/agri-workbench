# 手机端麦克风与相机：为什么必须走 https，以及怎么配

> 面向使用者（园区员工/管理员）。一句话：**浏览器只在"安全页面"里提供麦克风和相机，
> 页面不是 https 就一定用不了，跟你有没有点"允许"没关系。**

## 一、先看现象对照

| 你看到的 | 真正原因 |
| --- | --- |
| 点了麦克风，提示"浏览器没有拿到麦克风权限"，但你已经授权过 | 页面是 `http://`，浏览器**根本没提供**麦克风接口。授权是给 https 页面用的，http 页面连弹窗都不会有 |
| 拍照提示"当前不是安全连接，无法使用页内相机" | 同上，`getUserMedia` 在 http 下不可用 |
| 点"系统相机"没反应 | 旧版前端的 file input 没插入 DOM，安卓上点了不弹（本轮已修） |

判断口诀：**地址栏是 `https://` 开头才有可能**。`http://` 一定不行。

## 二、现在可以用的两个入口

| 入口 | 地址 | 麦克风 | 页内相机 | 系统相机 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 公网 HTTPS（推荐） | `https://42.193.104.148` | 可用 | 可用 | 可用 | 需先装一次根证书 |
| 内网 HTTPS | `https://192.168.0.141:8543` | 可用 | 可用 | 可用 | 园区内网用，同样要装根证书 |
| 公网 HTTP（明文） | `http://42.193.104.148:8080` | **不可用** | **不可用** | 可用 | 只能打字 + 用系统相机拍照 |

## 三、第一次使用：装根证书（只装一次）

根证书只对京阳自己的服务器生效，浏览器对其它网站照常校验。

1. 在手机浏览器打开 **`http://42.193.104.148:8080/jingyang-ca.crt`** 下载
   `jingyang-ca.crt`（也可以打开 `http://42.193.104.148:8080/ca.html` 看同样的说明页）。
2. 按系统提示安装：

   **安卓（Chrome / Edge）**
   「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」→ 提示风险选「仍然安装」→
   选中刚下载的 `jingyang-ca.crt`。

   **iPhone / iPad（Safari）**
   下载后「设置 → 已下载描述文件 → 安装」，再到
   「设置 → 通用 → 关于本机 → 证书信任设置」，把
   `Jingyang Local Root CA` 的开关打开。

3. 浏览器访问 `https://42.193.104.148`，地址栏不再报证书错误即成功。

## 四、装完还是不行？按这个顺序查

1. 地址必须是 `https://42.193.104.148`（不带端口、不带 www、不要用 http）。
2. 浏览器提示"不安全"就是证书没装好或没信任：安卓要装到 **CA 证书**；
   iOS 装了描述文件后**还要去"证书信任设置"里打开开关**，只装描述文件是不够的。
3. 麦克风被拒（提示"麦克风权限被拒绝"）是另一回事：这时页面已经是 https 了，
   去系统设置里允许本应用使用麦克风。
4. 都正常但仍失败：把报错截图发服务器侧，隧道与代理日志能直接定位。

## 五、绕不开的替代方案

- **只用打字提问**：任何入口都能用。
- **只用拍照**：http 入口下用"系统相机"即可（页内相机不可用，但系统相机不受影响）。
- **完整语音 + 拍照**：必须 https，即先装根证书。
- **「京阳智农」安卓应用**：应用内走原生录音与拍照，不受浏览器安全上下文限制，
  是最省事的一条路。

- 服务端证书：`deploy/tls/agri-public.crt`，SAN 含 `42.193.104.148`、`192.168.0.141`、
  `127.0.0.1`、`localhost`、`qinghe.local`、`ai.qinghe.local`，有效期至 2029-01-28。
- 根证书：`/home/jingyang/agri-ca/ca.crt`（`Jingyang Local Root CA`）。
- 证书下载服务：`agri-ca-guide.service`（只提供证书与引导页，不含业务接口）。
- 隔离栈（原 8099/8443）的公网 HTTPS 已让出 443，迁到 8444。
