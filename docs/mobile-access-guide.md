# 手机端使用指南（免装证书版）

> 更新：2026-10-28。原先的"装根证书"方案已不再是推荐路径——现在有**零安装**的办法。

## 一句话

手机浏览器打开 **`http://42.193.104.148:8080/entry.html`** → 点页面上的大按钮 → 进工作台。
麦克风、相机都能直接用，**不用装证书、不用改任何设置**。

---

## 为什么以前"能用"、现在要这一步

不是"多了个步骤"，而是**手机浏览器的硬性规则**：

麦克风（`getUserMedia`）和页内相机**只在「安全上下文」里才存在**。浏览器判定安全上下文的方式：

| 访问方式 | 是安全上下文吗 |
|---|---|
| `http://` 普通地址 | ❌ 浏览器直接把 `navigator.mediaDevices` 整个抹掉，连调都调不到 |
| `https://` + 浏览器信任的证书 | ✅ |
| `http://localhost` / `127.0.0.1` | ✅（但手机不是 localhost） |

以前你访问的是 `http://42.193.104.148:8080`，属于第一种——所以文字问答能用（那走普通 HTTP 就行），
但麦克风和相机从来没通过。前端 catch 到异常后统一显示"浏览器没有拿到麦克风权限"，
**那句话是误导的**：不是权限问题，你授权多少次都没用。

---

## 现在的三条路

### 方案 A：Cloudflare Tunnel 入口（推荐，零安装）

**入口：`http://42.193.104.148:8080/entry.html`**

打开后页面会显示一个 `https://xxx.trycloudflare.com` 地址和一个大按钮，点进去即可。

原理：Cloudflare 边缘用公共 CA（Google Trust Services）签发证书，手机浏览器**原生信任**，
不需要装任何东西。页面因此是安全上下文，麦克风和相机直接可用。

已实测（真实 Chrome）：`isSecureContext=true`、`getUserMedia` 成功、
**麦克风音轨取到**、**相机画面取到**、隧道下登录成功。

**注意**：隧道地址在服务重启后会变。所以请收藏**入口页**，不要收藏隧道地址本身——
入口页每次打开都会读实时地址。

### 方案 B：装根证书（备用，仍然有效）

入口：`http://42.193.104.148:8080/ca.html`

证书已改成 `application/x-x509-ca-cert`，安卓 Chrome 点了会直接弹系统安装界面。
页面提供三条路径：一步安装 / 下载后手动装 / 复制文本另存为 .crt。

### 方案 C：直接用 IP + 自签证书（最快，但需要装证书）

`https://42.193.104.148` —— 延迟最低（0.17 秒），但必须先按方案 B 装好根证书。

## 三个入口的能力对照

| 入口 | 文字问答 | 麦克风 | 页内相机 | 系统相机 | 延迟 |
|---|---|---|---|---|---|
| `https://42.193.104.148`（装了证书） | ✅ | ✅ | ✅ | ✅ | **0.17 秒** |
| `https://xxx.trycloudflare.com`（方案 A） | ✅ | ✅ | ✅ | ✅ | 1~2 秒 |
| `http://42.193.104.148:8080`（明文） | ✅ | ❌ | ❌ | ✅ | 0.17 秒 |

> 方案 A 慢一点是因为请求要绕 Cloudflare 边缘（源站在国内，边缘在境外）。
> 语音对话对首字节延迟比较敏感，如果觉得慢，用方案 B + 方案 C 组合。

## 常见问题

**点按钮没反应 / 页面一直转？**
- 检查地址栏是不是 `https://` 开头。
- 微信/QQ 内置浏览器**不支持**这些接口，请用系统浏览器（Chrome / Edge / Safari）打开。

**进去了但麦克风还是不行？**
- 安卓 Chrome：右上角菜单 → 设置 → 网站设置 → 麦克风 → 允许。
- 相机同理，在「网站设置 → 相机」里允许。
- 部分国产 ROM 还要在「设置 → 应用 → 浏览器 → 权限」里单独允许。

**页面提示"当前是 http 访问"？**
说明你还在明文入口。用方案 A 的入口页跳转。

## 服务端怎么维护的

| 位置 | 东西 |
|---|---|
| 云服务器 `~/.config/systemd/user/cf-tunnel.service` | 隧道常驻服务，自启 + 异常自动重启 |
| 云服务器 `~/cf-tunnel/current-url.txt` | 当前隧道地址（每次启动更新） |
| 云服务器 `/var/www/cf-url.txt` | 上面那个文件的对外副本，nginx 暴露成 `/cf-url.txt` |
| 141 `app/dist/entry.html` | 入口页 |
| 141 `deploy/gateway.mjs` | `/cf-url.txt` 路由（代理到云端 nginx） |
| 141 `app/server/origin-guard.mjs` | 来源白名单，支持 `https://*.trycloudflare.com` 通配 |

查当前地址：`cat ~/cf-tunnel/current-url.txt`（云服务器）
重启隧道：`systemctl --user restart cf-tunnel.service`

**重要**：quick tunnel 没有 SLA，域名每次重启都会变，Cloudflare 也可能随时收回。
入口页是动态读的，所以不受影响；但如果某天入口页拿不到地址，就看这个服务是不是挂了。
